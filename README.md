The program writes a single 147-character text to `/output/entry.txt` — a text that calms by showing, not telling: a porch light staying on after the street has gone quiet, a small warm square in the dark, nothing out there asking anything of you tonight.

The text was picked by blind pairwise judging in `judge-lab` (7 texts, 21 matches, judged only by the competition's printed criteria in order): it won 6 of 6, beating the tide, armchair, and dust variants plus three house anchors (weak 0/6, mid 1/6, strong 3/6).

## Run it

```sh
python3 main.py
```

Python 3.13, standard library only, no network, deterministic — the same text is written on every run.
